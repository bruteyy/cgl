## Common setup
These examples use the classic Turbo C++ BGI path:
`C:\\TURBOC3\\BGI`

If your compiler stores BGI files elsewhere, change the path in `initgraph()`.

## Main graphics functions
- `line(x1, y1, x2, y2)` draws a line.
- `rectangle(x1, y1, x2, y2)` draws a rectangle.
- `circle(x, y, radius)` draws a circle.
- `ellipse()` can be used for oval shapes.
- `setcolor(color)` changes the outline colour.

These are outline drawings, designed to make the basic shapes easy to understand and modify.
